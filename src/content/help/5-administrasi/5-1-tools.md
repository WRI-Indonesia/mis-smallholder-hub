**Dashboard Snapshot** — Membuat rekaman data terbaru untuk dashboard. Ada dua menu terpisah: **Dashboard Snapshot** untuk Main Dashboard dan **Dashboard Snapshot BMP** untuk BMP Dashboard — men-generate yang satu tidak memperbarui yang lain. Jalankan setelah input atau import data dalam jumlah besar agar angka dashboard mengikuti data terkini. Menu Tools secara bawaan hanya untuk SUPERADMIN dan ADMIN.

**Riwayat snapshot** — Snapshot lama tetap tersimpan dan dapat dilihat atau diunduh sebagai Excel; tombol unduhnya hanya tampil bila akun Anda punya izin **Export** pada menu ini. Dari halaman detail snapshot **Dashboard Snapshot** (Main Dashboard), data yang sama juga bisa diunduh sebagai PDF (ringkasan KPI + tabel per Lembaga Petani, sesuai tanggal snapshot); tombolnya hanya tampil bila akun Anda punya izin **Print**.

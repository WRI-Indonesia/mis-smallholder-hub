**Dashboard Snapshot** — Membuat rekaman data terbaru untuk dashboard. Ada dua menu terpisah: **Dashboard Snapshot** untuk Main Dashboard dan **Dashboard Snapshot BMP** untuk BMP Dashboard — men-generate yang satu tidak memperbarui yang lain. Jalankan setelah input atau import data dalam jumlah besar agar angka dashboard mengikuti data terkini.

**Riwayat snapshot** — Snapshot lama tetap tersimpan dan dapat dilihat atau diunduh sebagai Excel.
